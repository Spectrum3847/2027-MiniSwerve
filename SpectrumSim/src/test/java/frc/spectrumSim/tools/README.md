# spectrumSim.tools

Command-line tools on the sim, run through Gradle.

| File | What |
|---|---|
| `SimReplay` | Replays a real match's module commands through the sim (`./gradlew simReplay`), for `tools/sim_vs_real.py` and `tools/fit_sim.py` |
| `TalonCrosscheck` | Same commands through Phoenix's simulator and our TalonFX model, compared (`./gradlew talonCrosscheck`) |

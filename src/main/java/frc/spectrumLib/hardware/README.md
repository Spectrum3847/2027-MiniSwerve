# hardware

| File | What |
|---|---|
| `FirmwareCheck` | Names devices of one type whose firmware differs from the rest, or could not be read |
| `PhoenixBackground` | Queues blocking Phoenix calls (config applies, setPosition) on one thread with retries; named results |
| `PhoenixDeviceSet` | A mechanism's devices kept configured all match: reboots noticed, configs and signal rates retried forever |
| `SimFaults` | Sim only: unplug, make unheard, reboot or fail configs of named devices |
